NOVO OS — форк Xanex OS 0.6 на чистом ассемблере x86.

Основа: ядро, загрузчик, драйверы ATA/PS2/VGA, файловая система, калькулятор и блокнот — из Xanex OS. Оригинал: https://github.com/eliseysadriev-bot/Xanex-OS-0.5/releases/tag/OS_Xanex

Добавлено нами:

    GUI в стиле Windows 95: верхняя панель с меню и часами, нижний док, иконки рабочего стола

    Терминал с 15 командами

    Файловый менеджер: Copy/Paste/Delete/New/Rename, открытие файлов

    Горячие клавиши F1–F4, Esc

    Буфер обмена Ctrl+C/Ctrl+V (текст и файлы)

    ATA IDENTIFY: модель и размер диска

    Меню программ, контекстное меню ПКМ

    Трёхцветный рабочий стол, настройки

Стек: NASM, x86 protected mode, VGA, ATA PIO, PS/2, RTC.

Статус: проект в разработке. Не всё работает — часть функций ещё в процессе. Автор форка не шарит за GitHub, так что оформление может быть кривым.

Лицензия: как у оригинала.

Автор доработок: Semen. Автор основы: автор Xanex OS.
